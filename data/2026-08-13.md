### [1] [Inferring Empirical Sound Resource Bounds via Symbolic Execution and Linear Programming (Extended Version)](https://arxiv.org/abs/2608.11833)
*Samuel Frontull,Manuel Meitinger,Georg Moser*

Main category: cs.PL

TL;DR: 本文提出了一种新颖的混合方法CompAS，结合动态符号执行与混合整数线性规划，为函数式程序的最坏情况资源消耗推导上界，弥补了纯静态分析与纯动态分析各自的不足。

  <summary>Details</summary>
Motivation: 现有资源分析方法分为静态分析和动态分析两大范式：静态分析能提供形式化保证但不完备；动态分析适用范围广但可能遗漏罕见的最坏情况场景，缺乏可靠性。混合方法试图结合两者优势，以分析对纯静态技术过于复杂或对动态方法存在组合爆炸的程序。

Method: 该方法将动态符号执行（用于在受限输入空间中穷尽探索所有可能的计算路径）与混合整数线性规划（用于推导经验上可靠的上界）相结合，系统性地推导函数式程序最坏情况资源消耗的上界。

Result: 作者将该方法实现为原型工具CompAS，并已在Zenodo平台上公开发布。

Conclusion: 通过混合动态符号执行与混合整数线性规划，CompAS能够有效分析那些对纯静态或纯动态方法都过于复杂的程序，为最坏情况资源消耗提供上界保证。

Abstract: Existing approaches to resource analysis of programs can be classified into two main paradigms: static analysis and dynamic analysis methods. The former allow for formal guarantees but are inherently incomplete; the latter are widely applicable but may miss rare but characteristic (worst-case) scenarios and thus lack soundness. Hybrid approaches attempt to combine the strengths of both paradigms, thereby enabling the analysis of programs that are either too complex for purely static techniques or where dynamic approaches suffer from combinatorial explosion. In this paper, we present a novel hybrid approach that systematically derives upper bounds for the worst-case resource consumption of functional programs. Our method combines dynamic symbolic execution to exhaustively explore all possible computation paths within a constrained input space with mixed-integer linear programming to derive empirically sound upper bounds. We have implemented the methodology in a prototype tool, dubbed CompAS, which we made available on Zenodo.
