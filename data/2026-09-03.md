### [1] [Synthesis of Compact and Expressive Quantum-Circuit Optimizations](https://arxiv.org/abs/2609.01762)
*Wei Qiang,Ronghui Gu*

Main category: cs.PL

TL;DR: QSymb是一个量子电路重写规则综合框架，通过形式化符号重写规则和规范的符号规则核心（L;S = S;R），自动合成紧凑且富有表达力的规则集，在IBM-Eagle和Nam门集上显著优于现有重写优化器，分别达到27.44%和29.95%的平均双量子比特门减少。


<details>
  <summary>Details</summary>
Motivation: 当前的量子设备存在噪声，减小电路规模对可靠执行至关重要。已有的基于规则的重写优化器依赖大量难以管理的规则集，且缺乏对长距离变换的处理能力，需要一种能自动综合紧凑且富有表达力的规则的方法。

Method: 提出QSymb框架：(1)形式化符号重写规则，其中符号门代表无限多个子电路；(2)定义规范符号规则形式L;S = S;R，并证明其构成可从一般符号规则推导的紧凑生成核心；(3)在给定门集上综合小规模非可导的完备具体规则集以及表达力强的规范符号规则集；(4)提出规则锚定技术，从规范符号规则中推导出优化有效的重写规则。合成规则的可靠性通过验证保证，同时确保不可导性和有界完备性。

Result: 在IBM-Eagle门集上，QSymb在双量子比特门减少指标上分别优于Qiskit、Guoq、Quartz、TKET和Queso（90%、67%、82%、85%和83%的标准量子算法基准测试）；在Nam门集上对应比例分别为88%、74%、81%、86%和82.9%。最终平均双量子比特门减少分别达到27.44%和29.95%。

Conclusion: QSymb通过形式化基础保证了综合规则的可推导性、不可导性和有界完备性，在保持规则集规模较小且非可导的同时具有高表达力，实证表明其全面优于现有的重写优化器。

Abstract: Today's quantum devices are noisy, so reducing circuit size is critical for reliable execution. Existing rule-based optimizers often rely on large rule sets that are difficult to manage and still miss long-distance transformations. We present QSymb, a framework for synthesizing compact and expressive quantum-circuit rewrite rules with formal guarantees. We formalize symbolic rewrite rules in which a symbolic gate represents infinitely many subcircuits. We then define canonical symbolic rules of the form $L;S = S;R$ and prove that they constitute a compact generative core from which general symbolic rules can be derived. On top of this formal foundation, given a gate set, QSymb synthesizes (1) a small, non-derivable concrete rule set that is complete up to chosen size and qubit bounds, and (2) a small but expressive canonical symbolic rule set that captures transformations beyond finite or monomial-only patterns. We further present rule anchoring to derive optimization-effective rules from canonical symbolic rules. Together, these results provide both expressiveness and guarantees: soundness of synthesized rules via validation, non-derivability, and bounded completeness. On the IBM-Eagle gate set, QSymb strictly outperforms state-of-the-art rewrite-based optimizers (Qiskit, Guoq, Quartz, TKET, and Queso) in two-qubit-gate reduction on 90%, 67%, 82%, 85%, and 83% of standard quantum algorithm benchmarks, respectively; on Nam gate set, the corresponding rates are 88%, 74%, 81%, 86%, and 82.9%. It achieves final average two-qubit-gate reductions of 27.44% and 29.95%, respectively.

### [2] [Unifying Function- and Argument-First Bidirectional Type Systems](https://arxiv.org/abs/2609.02005)
*Takuma Yoshioka,Taro Sekiyama,Atsushi Igarashi*

Main category: cs.PL

TL;DR: 本文提出λ^{BH}，一个统一双向类型系统中"函数优先"（function-first）和"参数优先"（argument-first）两种风格的新型类型系统。通过在每个函数应用中标注一位信息来表示使用哪种风格，并借鉴colored types和boxy types的思想灵活指定类型中哪些部分用于合成或检查。该系统支持高阶多态，其声明式类型系统是可靠且可包含两种代表性子系统的，算法也被证明与两种代表性子系统兼容，并使用Abella定理证明器进行机械化验证。


<details>
  <summary>Details</summary>
Motivation: 现有的双向类型系统根据函数应用的处理方式被分为"函数优先"和"参数优先"两种风格，这两种风格在形式化和类型能力上不兼容，迫使语言设计者只能选择一种风格而放弃另一种的类型能力。作者希望统一这两种风格，使语言设计者（甚至程序员）可以自由切换而不丢失任一种风格的类型能力。

Method: 1) 在每个函数应用中标注一位信息来表示使用函数优先还是参数优先的类型推断风格，允许设计者/程序员按需切换。2) 通过引入colored types和boxy types的思想，重新形式化函数优先和参数优先类型系统，从而灵活指定哪些类型部分用于合成、哪些用于检查。3) 基于Zhao等人提出的worklist方法开发了类型推断算法。

Result: λ^{BH}的声明式类型系统被证明是可靠的（sound），并且能包含（subsume）两种具有代表性的函数优先和参数优先系统。其类型推断算法相对于λ^{BH}类型系统是可靠的，相对于两种代表性系统是完备的。所有元定理均使用Abella定理证明器进行了机械化证明。

Conclusion: 通过统一两种此前不兼容的双向类型推断风格，λ^{BH}为语言设计者和程序员提供了更大的灵活性，消除了在不同风格间做出选择时必须放弃某些类型能力的限制。机械化的证明保证了系统理论性质的可靠性。

Abstract: Bidirectional typing mixes type synthesis and type checking into a single process. Existing bidirectional type systems can be classified into two styles based on whether, given a function application, a bidirectional typing algorithm synthesizes the function's type first and typechecks the argument against the synthesized argument type, or it synthesizes the arguments' types first and typechecks the function against the synthesized arguments' types. We call the former _function-first_ and the latter _argument-first_. Not only do the two styles significantly differ in how the type systems and typing algorithms are formalized, but also they lead to incompatible typeabilities, forcing a language designer to select one style and to give up the other's typeabilities.
  In this paper, we unify the two styles and develop \lang with a new bidirectional type system for higher-rank polymorphism. Key ideas of the unification are twofold. Each function application is annotated with a bit of information to represent whether function- or argument-first typing is used, to allow a language designer (or even a programmer) to switch between the two styles at their discretion. We reformulate the function- and argument-first type systems by using ideas from colored types and boxy types, which can specify which part of a type should be synthesized or used for checking in a flexible manner. We also develop a typing algorithm based on the worklist approach by Zhao et al.
  The (declarative) type system of $λ^{BH}$ is shown to be sound and to subsume two representative function- and argument-first systems. Our typing algorithm is shown to be sound with respect to the type system of $λ^{BH}$ and complete with respect to representative function- and argument-first systems. We mechanically prove the metatheorems using the Abella theorem prover.

</details>

### [4] [GadIR: A Spatial-Topology Preserving Compiler for Quantum Many-Body Systems Simulation](https://arxiv.org/abs/2609.01771)
*Xiangyu Ren,Yuexun Huang,Zhaohui Yang,Yuchen Zhu,Tsung-Wei Huang,Tsung-Yi Ho,Zhiding Liang,Antonio Barbalace*

Main category: quant-ph

TL;DR: 本文提出了一种保留空间拓扑结构的量子编译器GadIR，用于量子多体系统模拟。通过使用Pauli gadgets作为哈密顿量的中间表示，该编译器在保留原始物理模型空间拓扑信息的同时，实现了硬件无关的前端优化（组约简算法）和硬件相关的后端优化（trotterization和调度），在四种主流量子架构上显著降低了编译开销。


<details>
  <summary>Details</summary>
Motivation: 传统的量子多体模拟编译方法将哈密顿量表示为Pauli strings，基于量子电路模型进行编译和优化。这种表示方式忽略了原始物理模型的空间拓扑结构，而该信息对于减少多体系统哈密顿量编译开销至关重要。

Method: 1) 引入GadIR作为中间表示，基于Paulic gadgets表示哈密顿量，保留原始物理模型的空间拓扑信息；2) 前端采用基于Pauli gadget模型的组约简算法，实现硬件无关的优化；3) 后端执行trotterization和pauli gadgets上的调度，然后将pauli gadgets合成为硬件原生量子程序。

Result: 在全部典型的量子多体系统模型上评估了该编译器，在四种主要量子架构上均实现了编译开销的显著降低。

Conclusion: 空间拓扑保留的中间表示（GadIR）开拓了量子多体系统哈密顿量编译的优化空间，表明利用物理模型的空间结构信息可以显著提升量子编译器的性能。

Abstract: Simulating quantum many-body systems has been one of the most important applications of quantum computation. For simulation, the Hamiltonian of a physical system is compiled into quantum programs with native instructions for quantum hardware. In previous works, the Hamiltonian is represented as Pauli strings, then compiled and optimized based on the quantum circuit model. Such representation paradigm neglects the spatial topology of original physical models, which is vital information to reducing the overhead of compiling many-body systems Hamiltonians.
  To address such neglect, we introduce a spatial-topology preserving compiler for quantum many-body simulation. Using Pauli gadgets as the representations of the Hamiltonian, we introduce our intermediate representation -- GadIR, to preserve the spatial-topology information of original physical models. Our compiler frontend performs the group reduction algorithm based on Pauli gadget model, which is a hardware-independent optimization. Our compiler backend performs trotterization and scheduling on Pauli gadgets, then synthesizes the Pauli gadgets into hardware-native quantum programs. We evaluate our compiler on all the canonical quantum many-body system models, while achieving a significant reduction on compilation overhead regarding four major quantum architectures. Overall, our spatial-topology preserving IR exploits the compilation optimization space for quantum many-body systems Hamiltonian.

### [5] [Type-Directed, Secure-by-Construction Enclave Partitioning for LLVM](https://arxiv.org/abs/2609.02048)
*Wesley B. Nuzzo,Samuel Dodson,Benjamin Houle,Tarakaram Gollamudi,Anitha Gollamudi*

Main category: cs.CR

TL;DR: 本文提出了SPLITR系统，通过三步方法解决TEE（可信执行环境）中的信息流安全和自动应用分区问题：形式化SIR演算（带信息流控制的类型系统与内存安全）、扩展为SIREN演算（支持对强攻击者的非干扰保证）、以及从SIR到SIREN的类型保持编译（自动生成安全的enclave感知程序，消除手动分区）。在Intel SGX上对13个微基准和真实工作负载（含OpenSSL）进行了评估。


<details>
  <summary>Details</summary>
Motivation: TEE虽然提供硬件级隔离，但单独使用无法强制信息流安全；LLVM类低级语言允许不受限制的指针操作和非结构化控制流，加剧了问题；且手动将应用分区为enclave和非enclave组件的过程劳动密集、易出错且缺乏细粒度控制。

Method: 三步方法：1) 形式化SIR（基于LLVM IR的enclave无关演算），配备新颖的宽松类型系统，结合信息流控制与安全感知的粗粒度内存安全来强制执行安全性；2) 扩展为SIREN（enclave感知演算），对能观察任意非enclave内存的更强攻击者执行非干扰保证；3) 开发从SIR到SIREN的类型驱动、类型保持的编译，自动生成安全的enclave感知程序。

Result: SPLITR在Intel SGX硬件上对13个微基准和真实工作负载（含SGXGauge应用）完成评估，可扩展至OpenSSL（425,953条LLVM IR指令），支持多个优化目标（TCB大小、host-enclave转换、边界数据移动）。对OpenSSL优化转换次数从393降至187。运行时开销对短时工作负载由固定enclave成本主导，长时应用则接近原生性能。

Conclusion: SPLITR通过类型驱动的自动分区方法，在保持安全保证（信息流控制与非干扰）的同时消除了手动分区负担，并为host-enclave边界提供了细粒度控制，在真实硬件上表现出良好的可扩展性和可接受的性能折衷。

Abstract: Trusted Execution Environments (TEEs) provide hardware-supported isolation through enclaves that protect code and data independently of software abstractions. However, TEEs alone cannot enforce information-flow security. This problem is further aggravated in LLVM-like low-level languages that allow unrestricted pointer manipulation and unstructured control flow. Moreover, using TEEs effectively typically requires manually partitioning applications into enclave and non-enclave components, a process that is labor-intensive, error-prone, and lacks fine-grained control.
  We address these challenges with a three-step approach. First, we formalize SIR, an enclave-oblivious calculus based on LLVM IR, equipped with a novel permissive type system that enforces security against low-level attackers. To obtain meaningful guarantees, SIR combines information-flow control with security-aware coarse-grained memory safety. Second, we extend SIR to SIREN, an enclave-aware calculus that enforces noninterference against stronger attackers capable of observing arbitrary non-enclave memory. Third, we develop a type-driven, type-preserving compilation from SIR to SIREN that automatically produces secure enclave-aware programs, eliminating manual partitioning while providing fine-grained control over host-enclave boundaries.
  We implement and evaluate SPLITR on thirteen microbenchmarks and real-world workloads, including applications from SGXGauge, on Intel SGX hardware. SPLITR scales to OpenSSL (425,953 LLVM IR instructions) and supports multiple objectives that expose trade-offs among enclave TCB size, host-enclave transitions, and boundary data movement. For OpenSSL, optimizing for transitions reduces them from 393 to 187. Runtime overhead is dominated by fixed enclave costs for short-running workloads, whereas long-running applications better amortize these costs and approach native performance.

</details>
