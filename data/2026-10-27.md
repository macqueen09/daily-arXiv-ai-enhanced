### [1] [A Rowhammer attack on Fil-C's software capabilities](https://arxiv.org/abs/2610.33748)
*Amir Naseredini,Suhas Viswanath,Martin Berger*

Main category: cs.PL

TL;DR: 本文提出了一个面向Rowhammer故障的理想化命令式语言的概率小步操作语义，抽象掉DRAM内部结构，并用一般概率故障模型参数化；作为案例研究形式化了物理隔离防御，证明了一个与分布无关的语义坍缩定理。


<details>
  <summary>Details</summary>
Motivation: Rowhammer使重复访问攻击行导致邻近受害行位翻转，违反"访问一处内存不会修改其他位置"的常规语言语义假设。然而目前缺乏将Rowhammer故障与程序行为联系起来的通用形式框架，难以严格论证各种Rowhammer防御的有效性及其提供的程序级保证。

Method: 为理想化命令式语言构建概率小步操作语义，高层地抽象掉DRAM内部与半导体物理细节；用一般概率故障模型参数化，即在读/写操作时对指定受害区域内的位翻转赋予概率；借助概率计算的标准monadic结构将所得分布沿程序传播。案例研究：形式化物理隔离（physical separation）防御，并发展观察参数化的安全信息流账户。

Result: 证明了分布无关的语义坍缩定理：对任意有限执行（包括终止与非终止执行的前缀），概率Rowhammer语义在受保护投影下是相应无Rowhammer执行所对应的Dirac分布。

Conclusion: 该工作建立了Rowhammer故障与程序语义之间的形式化桥梁，为严格推理防御有效性提供基础；物理隔离在此框架下被证明可完全消除可观察的Rowhammer影响，并给出观察参数化的安全信息流分析框架。

Abstract: Rowhammer is a hardware vulnerability in dynamic random-access memory (DRAM) in which repeated accesses to one or more aggressor rows can induce bit-flips in nearby victim rows. This phenomenon violates a core assumption of conventional programming language semantics: that reading from or writing to one memory location does not modify others. Despite the security importance of this phenomenon, there is no widely established formal framework connecting Rowhammer faults with program behaviour. This makes it difficult to reason rigorously about the efficacy of proposed Rowhammer defences and the program-level guarantees they provide. To address this gap, we present a probabilistic small-step operational semantics for an idealised imperative language subject to Rowhammer-style faults. The semantics is high-level in that it abstracts from DRAM internals and semiconductor physics. A general probabilistic fault model parameterises the semantics, representing Rowhammer-style faults by assigning probabilities to bit-flips during read or write operations within a specified victim region. The resulting distributions are propagated through programs using the standard monadic structure of probabilistic computation. As a case study, we formalise physical separation, a well-known defence that places program variables sufficiently far apart in physical memory that an access to one variable cannot disturb another. We prove a distribution-independent semantic collapse theorem: for every finite execution, including prefixes of terminating and non-terminating executions, the protected projection of the probabilistic Rowhammer semantics is the Dirac distribution of the corresponding Rowhammer-free execution. Furthermore, we develop an observation-parametric account of secure information flow.

### [3] [Connecting Quantum Proof Systems and Hoare Logic](https://arxiv.org/abs/2610.34723)

TL;DR: Qafny 量子程序证明系统可完全且可靠地翻译为带数组理论的 Hoare 逻辑，并用 Rocq 机械化完备性，使量子验证复用经典自动验证器而无需专用量子证明系统。


<details>
  <summary>Details</summary>
Motivation: 当前量子程序验证依赖 Rocq、Lean、Isabelle、Why3 等上的专用证明系统，即使简单量子算法也需大量人工，而量子程序无法用运行时测试检查，形式验证是唯一正确性保障，因此这些定制系统的高成本成为可扩展量子软件保障的主要瓶颈。

Method: 作者证明量子程序验证不应比经典数组程序验证更难：将 Qafny 翻译为含数组理论的 Hoare 逻辑，证明该翻译完全（每个 Qafny 证明都成为合法 Hoare 三元组）且可靠（合法翻译三元组只证明真实量子规范），并在 Rocq 中机械化完备性方向。该嵌入对量子证明义务去确定化，从而让 Dafny 和基于 SMT 的分离逻辑等经典自动验证器可直接作用于量子代码。

Result: 获得嵌入的完备性与可靠性；该嵌入还为现有 Qafny 到 Dafny 的编译提供了此前缺失的正确性论证。

Abstract: Verifying quantum programs today requires specialized proof systems built on interactive theorem provers such as Rocq, Lean, Isabelle, or Why3, and even modest quantum algorithms cost substantial human effort to verify. Because quantum programs cannot be effectively checked by runtime testing, formal verification is the only viable path to correctness, making the cost of these bespoke systems the chief barrier to scalable quantum software assurance. The embedding determinizes quantum proof obligations and exposes the full machinery of classical automated verifiers (e.g. Dafny and SMT-based separation logic) to quantum code, removing the need for dedicated quantum proof system infrastructure. In particular, the embedding supplies the correctness argument that the existing compilation of Qafny into Dafny lacks.
