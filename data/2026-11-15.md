Method: 提出一般多参与者会话类型的概率扩展，无全局规范、自底向上类型化；类型结合概率选择与抽象数据相关控制的不确定性选择，并允许分离选择；引入新的概率子类型关系与合并算子证明类型健全性与会话保真性；类型上下文语义分离不确定性消解、概率选择与同步，使每个上下文诱导有限马尔可夫决策过程。

The semantics of typing contexts separates nondeterministic resolution, probabilistic choice, and synchronisation, so that every typing context induces a finite Markov decision process. On it, we derive sound lower bounds, holding under every fair adversarial scheduler, on the probability that a session is deadlock-free and live - the first behavioural property guarantees, partial or otherwise, for a probabilistic session calculus. To connect session types with probabilistic model checking, we introduce the first translation from session types into the PRISM modelling language, and prove it sound and complete with respect to our operational semantics. We implement the framework in the toolchain Prose, which translates probabilistic multiparty session typing contexts into PRISM and checks safety, deadlock-freedom, and liveness.

### [4] [Reconstructing Fine-grained Memory Reuse Structure in GPU Kernels](https://arxiv.org/abs/2611.14741)
*Yanbo Zhao,Yueming Hao,Zecheng Li,Mao Lin,Shuyin Jiao,Keren Zhou,Xu Liu,Jiajia Li*

Main category: cs.DC

TL;DR: 提出Topological Distance与PCDepGraph两种抽象表示GPU内存复用结构，并实现工具cuVein，从优化后二进制直接重建该图（无采样，开销普遍低于10x），据此指导优化可减少高达90.18%内存指令、加速最高2.84x。


<details>
  <summary>Details</summary>
Motivation: 优化GPU数据移动需知道哪些指令访问相同数据及跨何种执行作用域发生复用。现有profiler只能将内存行为归因到单条指令却不暴露指令间复用关系；别名、动态索引与运行时参数又使静态分析难以建立这些关系；周期级模拟虽可重建但成本过高。

Method: 定义两个抽象：Topological Distance（为每个动态内存访问标注包含其最近一次复用的最小执行作用域：thread/warp/block/grid）；PCDepGraph（把这些标签组织成PC级图，描述kernel内存复用结构）。表示基于逻辑执行作用域而非瞬态硬件状态，跨运行与GPU目标稳定。工具cuVein从优化二进制直接重建PCDepGraph，无需采样且开销普遍低于10x。

Result: 在NVIDIA RTX 4090与H100上针对HPC与AI负载：PCDepGraph指导的优化消除高达90.18%内存指令，kernel加速最高2.84x；复用作用域分布在跨平台间保持一致，支持该表示捕捉的是程序结构而非瞬态硬件行为。

Conclusion: PCDepGraph是一种稳定、低成本可重建的GPU内存复用结构表示，能直接指示优化机制需覆盖的共享作用域，有效指导GPU数据移动优化并具备跨平台一致性。

Abstract: Optimizing GPU data movement requires knowing which instructions access the same data and across which execution scopes reuse occurs. Existing profilers can attribute memory behavior to individual instructions but do not expose the reuse relations among them, while aliasing, dynamic indexing, and runtime parameters prevent static analysis from establishing these relations in general. Cycle-level simulation can reconstruct such relations, but at costs prohibitive for production workloads. We introduce two abstractions for representing this structure: Topological Distance, which labels each dynamic memory access with the smallest execution scope (thread, warp, block, or grid) containing its most recent reuse, and PCDepGraph, which organizes these labels into a PC-level graph of the kernel's memory reuse structure. Defined over logical execution scopes rather than transient hardware state, the representation remains stable across runs and GPU targets while directly indicating the sharing scope that candidate optimization mechanisms must cover. Our tool, cuVein, reconstructs PCDepGraph directly from optimized binaries, without sampling, at generally under 10x overhead. Across HPC and AI workloads on NVIDIA RTX 4090 and H100, optimizations guided by PCDepGraph eliminate up to 90.18% of memory instructions and yield up to 2.84x kernel speedup; reuse-scope distributions remain consistent across platforms, supporting that the representation captures program structure rather than transient hardware behavior.

</details>
